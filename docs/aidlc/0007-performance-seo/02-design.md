# 02 · Design — Performance & SEO

| #   | Decision                                                                                                                                                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | **The hero renders as one unit.** The stage illustration moves inside the hero's `@if (data)`, so nothing in the hero paints before its text.                                                                                                                                                                                                                    |
| D2  | **Metric-matched fallback fonts.** `@font-face` "DM Sans Fallback" and "Bricolage Grotesque Fallback" use `local(Arial)` with `size-adjust` and `ascent-`/`descent-`/`line-gap-override`, measured in Chrome. They sit second in the font tokens, so the swap barely moves text. Google Fonts keeps `display=swap`.                                              |
| D3  | **Lighter photos.** The experience, drum-circle and team JPEGs are re-encoded at their display needs (at most 1200 px wide, quality about 72) under the same file names, so no data change or seed is needed.                                                                                                                                                    |
| D4  | **`modulepreload` for the Firestore chunk.** A `postbuild` script finds the `firestore-gateway` chunk (named chunks in production) and adds `<link rel="modulepreload">` to `index.html`. The SDK then downloads in parallel with `main.js` instead of after it.                                                                                                 |
| D5  | **SEO metadata per route.** Route data carries each page's description; titles already live in routes. A root `SeoService` writes the description, canonical link, Open Graph and Twitter tags on every navigation. It's driven from `SiteShellViewModel`'s stream, so no service subscribes. URLs come from `environment.siteUrl`. Admin routes stay `noindex`. |
| D6  | **`LocalBusiness` JSON-LD built from `site/config`** by `SeoService`: name, address, phone, email, URL, logo, `sameAs` social links. It's a `<script type="application/ld+json">` data block, which CSP doesn't execute. Nothing is stored twice.                                                                                                                |
| D7  | **`robots.txt` and `sitemap.xml`** are generated by the same `postbuild` script from `SITE_URL` (default: `environment.siteUrl`). `/admin` is disallowed.                                                                                                                                                                                                        |
| D8  | **Social image:** a 1200×630 card (`public/images/og/taal-yatra.jpg`) rendered from the hero art.                                                                                                                                                                                                                                                                |
| D9  | **Accessibility names:** the brand link's visible text gets the missing space. Video cards hide the duration badge from assistive technology (`aria-hidden`), so their name contains the visible title.                                                                                                                                                          |
